# Prism Breaker

スマートフォンを最優先に設計した、外部ライブラリ不要のブロック崩しゲームです。Canvas と Web Audio API を使い、GitHub Pages でそのまま公開できます。

## 遊び方

- **スマートフォン:** ゲーム画面を左右になぞると、指の横位置にパドルが追従します。画面タップでボールを発射します。
- **PC:** マウス移動または左右キーで操作し、クリックまたは左右キーで発射します。
- 右上の `Ⅱ` で一時停止、`♪` でサウンドの ON/OFF を切り替えられます。

耐久ブロックを含む4種類のステージ（以降は繰り返し）と、ワイドパドル、マルチボール、スロー、スコアボーナスのアイテムがあります。

## ローカル起動

```bash
python3 -m http.server 8000
```

ブラウザで `http://localhost:8000/` を開いてください。

## 構成

- `index.html` — UI とゲーム画面
- `style.css` — モバイルファーストのレスポンシブデザイン
- `game.js` — ゲームループ、衝突判定、ステージ、音、エフェクト

すべて相対パスで参照しているため、GitHub Pages のプロジェクトサイトでも動作します。
